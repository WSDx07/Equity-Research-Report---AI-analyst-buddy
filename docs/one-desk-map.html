File arrows, by name

These are the file handoffs in the diagram. The worksheet reads the team's saved files and reuses matching filing text.

seeker/spinoff-screen-*.md→Pick reads the ranked report. seeker/registry-*.json→Pick and worksheet use the registry. seeker/filing_reads.json→Final report lists the filings on line one. team/facts.json→Worksheet reads the saved team run. team/*_10-K_*.txt, *_10-Q_*.txt, *_8-K_*.txt, Form 10 files→Worksheet source collector reuses matching saved filings. team/verified_report.md→Final report builder includes the team's verified report. team/worksheet-*.md→Final report builder adds the worksheet view. team/worksheet-*.md→Hook checks the worksheet output. final_report.md→Hook validates it; page displays it. run.json→Replay reads the saved report and paths.

Two input paths

Ticker

One Desk skips the seeker, selects the entered ticker, then calls the agent team and worksheet. If the ticker is absent from the registry, the worksheet marks spinoff-specific fields not applicable and continues.

Screen

One Desk runs the seeker, reads its ranked report, then passes the top ticker to the agent team and worksheet.

Empty screen

If the report says None established., pick, agent team, and worksheet are marked not applicable because no ticker is available. One Desk saves the report and filing list, runs the empty-screen hook, and records the run in run.json.

Commands

.\.venv\Scripts\python.exe one_desk.py VYLR
.\.venv\Scripts\python.exe one_desk.py screen
.\.venv\Scripts\python.exe one_desk.py --replay ".\one_desk_runs\VYLR_TIMESTAMP"

Replay checks saved files and runs the hook. It does not fetch filings. Each part records its elapsed seconds in the terminal and in run.json.
